Only generated research data/run payloads are in that archive. Project code,
source metadata, dataset/run manifests, fitted models, summaries and the durable
ledger remain in Git. Extract the archive at repository root before running the
frozen reproduction commands. The link requires the owner's account; no public
data release or sharing permission has been created.

Each source manifest records URLs, retrieval time, race dates, Last-Modified,
ETag, raw SHA-256 and byte count for six approved endpoints. Endpoint and calendar
metadata are frozen independently. Acquiring a new copy does not replace this run.

Each dataset manifest binds full canonical observations, initialization,
retrospective catalog, resolutions, model-input projections and separate labels.
The imported manifest preserves the earlier hashes; packing changes the lossless
codec and adds projection lineage. Canonical artifact bytes remain unchanged.

Each fold records its training and validation races, first-validation-race cutoff,
registration hash, all four module hashes, actual Python/NumPy/SciPy versions,
dataset manifest hashes, model identity, saved forecast/score hashes and run ID.
The append-only development ledger records target openings before joins. The
four folds use the exact P-F1 chronological partitions, and no 2026 input exists.

The final reviewed tree is published through the connected GitHub API. Frozen
artifacts retain their execution-time local repository revision strings and exact
module/content hashes. Those local commit IDs are not GitHub links. The optional
Git-history bundle was omitted after automatic approval review rejected its
upload over concerns about private repository history.

The first reconstruction process began while its resume-hash correction was
being committed. Its recorded revision is ddc6c70, while its explicit code hash
binds the corrected files from local revision 32af3a4. That historical revision
string is retained rather than rewriting original canonical artifacts. Source
and canonical payload hashes remain directly verifiable. Fresh reconstruction
produces new identities; frozen numerical results and model parameters can be
reproduced from the verified model-input dataset and current hashed fitting code.

The approved archive evidence exception and RA-1–RA-4 remain part of every dataset
manifest and report. Missing or indeterminate evidence is never filled from final
classifications or future tyre state.
