# Reproduction evidence

The detailed feature evidence and completed validation/refit artifacts are delivered
privately. The private evidence receipt supplies their exact retrieval and checksum
information. Restore those archives at repository root before using README.md.

The feature archive contains the causal feature projections and their verification.
The validation archive contains completed folds, fitted forests, predictions,
scores, diagnostics, selection, refit, actual opening ledger and completion records.
Original model and forecast identities are retained. The README explains the
aggregate serialization recovery and explicit provenance repair.

Git contains implementation, methods, aggregate findings and independent reviews.
