# Legacy thesis evidence

This directory records evidence distilled from thesis-era artifacts, commits, and historical branches.

`main` is the evolving V2 integration branch. Thesis-era artifacts and commits that predate the V2 bootstrap and remain reachable from `main` are legacy evidence/baselines, not V2 semantic authority. The separate branches `training_rf`, `training_svm`, and `cleaning` are historical thesis branches.

Specification work may inspect and cite that historical material, but must not rewrite/delete it or merge the historical branches unless a later explicit task authorizes that action.
